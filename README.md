## 📌 Sobre o Projeto
Este repositório é uma evolução tecnológica e pessoal do trabalho que desenvolvi para a **Prefeitura Municipal de Cachoeiras de Macacu**. O projeto original pode ser encontrado na aba de Sustentabilidade do site oficial, que direciona para a Universidade Corporativa para a Sustentabilidade de Cachoeiras de Macacu (https://site-secretaria-sustentabilidade.vercel.app/universidade.html).

Após criar e implementar a estrutura baseada nas **ODS (Objetivos de Desenvolvimento Sustentável)** para o município, decidi criar este "Hub Pessoal" para expandir as funcionalidades, modernizar a interface e aplicar novas lógicas de programação que vão além das necessidades institucionais.

## 🛠️ Evolução e Diferenciais
Diferente da versão oficial, este projeto foca em:
- **Independência de Dados**: Migração do sistema de planilhas (Google Apps Script) para uma estrutura estática mais rápida e performática.
- **Organização por Blocos Temáticos**: Uma nova forma de navegar por cursos, focada em trilhas de aprendizado (Tecnologia, Gestão, IA).
- **Foco em Redirecionamento**: Interface otimizada para atuar como um portal de curadoria rápida.

## 🔮 O Futuro (Roadmap)
O projeto está em fase inicial e pretendo implementar:
- [ ] **Integração com IA**: Uso de inteligência artificial para recomendar cursos baseados no perfil ou objetivo de carreira do usuário.
- [ ] **Trilhas de Carreira**: Agrupamento de cursos que ajudam a preencher requisitos para vagas específicas.
- [ ] **Filtros Avançados**: Separação entre conteúdos gratuitos e pagos.
- [ ] **Modernização UI/UX**: Uso de bibliotecas modernas para uma experiência de usuário mais fluida.
